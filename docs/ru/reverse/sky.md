# Небо и время суток RTS

> Перевод [`docs/reverse/sky.md`](../../reverse/sky.md). Основной текст —
> английский: при расхождении верен он.

Состояние: статический анализ `rts1.exe` (2021-08) плюс
`GLOBAL/SHADERS/sky.*` и `satellite.*`. Реализовано в
`formats/src/environment.cpp`, `renderer/src/rts_sky.cpp` (CPU) и
`renderer/src/sky_renderer.cpp` (GPU).

## Загрузка окружения (`0x55859C`)

### CONFIRMED

- Времена проявления слоёв: окно проявления сохраняется, только если есть
  `world_sky_layer_fadeout`. Нормализация: начало/конец появления
  `-= 86400`, если они после начала исчезновения; конец исчезновения
  `+= 86400`, если он до начала исчезновения.
- Геометрия слоя: центр купола `(0, H, 0)`, кольцо из `nfaces` вершин под
  углом `-k·2π/n`: `(-R sin a, H, -R cos a)`, uv
  `tiles/2 · (sin a, cos a) + tiles/2`. Шаг края `m` масштабирует
  предыдущее кольцо на `r_m / r_{m-1}` на высоте `h_m`; его uv растёт от
  центра на `|h_{m-1} − h_m| / H + r_m / r_{m-1}`. Упаковывается
  (`0x565CCC`) как веер треугольников (`n + 2`) плюс по одной полосе
  треугольников на шаг (`2n + 2`, первая пара повторена).
- `terrain_texslot ( name a b )`: `a == 2` — прижатие (clamp), иначе
  повтор.
- Спутники: время восхода `-= 86400`, если оно после времени захода. Если у
  спутника 0 `world_sky_satellite_light ( 0 )`, каждый следующий спутник со
  светом 1 переставляется в ячейку 0 (побеждает последний). Во всём
  остальном ячейка 0 — солнце.
- `world_environment_ambient_light` (шестнадцатеричное), по умолчанию
  `DefaultAmbientLight` из настроек, — нижняя граница `Light[0].Ambient`.

## На каждом кадре (`0x417D74`)

### CONFIRMED

Для каждого спутника, где `t` — время суток:

- сумеречный запас `m = |set − rise| / 10`, масштабированный на
  `(180 − rise_position)/90`, когда тайл камеры по Z ≥ 12384, иначе на
  `(rise_position − 180)/90`;
- виден, когда `rise − m ≤ t ≤ set + m`; первый спутник решает, ночь ли
  (`t < rise || t > set`);
- `w = 1 − |culmination − t| / half_day`; азимут из `rise_position` и `w`
  (две ветви по Z тайла); высота `sin(w·π/2) · E`, где
  `E = (16384 − tile_z)·0.0225°` со сгибом на 90°, `+22.5°` летом, `−22.5°`
  зимой;
- масштаб `(low·(1−w) + high·w)/100`;
- рассеянный и прямой цвета смешивают цвета восхода / зенита / заката с
  весами из сумеречного запаса; каналы ≥ 256 насыщаются, меньшие
  обрезаются до байта.

Азимут, высота, рассеянный и прямой цвета спутника 0 становятся `Light[0]`,
а его направление — `(sin az·cos el, −sin el, −cos az·cos el)`.

Цвет очистки = прямой цвет солнца. Туман неба: цвет = прямой цвет солнца
(приглушённый, когда солнце ниже −0.04°), начало 300 м, конец = max(500,
радиус последнего края видимых слоёв − 100).

Слои рисуются по порядку без проверки глубины; спутники рисуются, когда
номер слоя доходит до `nlayers_behind_satellites + 1`. Прозрачность слоя:
появление `1 − (end − t)/(end − start)`, исчезновение
`1 − (t − start)/(end − start)`, 0 вне окна. Непрозрачные шейдеры (`tex`,
`texdiff`) смешиваются только во время проявления; `blendatex*`/`addatex*`
смешиваются всегда (`SRC_ALPHA, ONE_MINUS_SRC_ALPHA`). Сдвиг UV копит
`scroll · dt` и заворачивается через `fmod 2`.

Спутники — четырёхугольники на 2000 м, половина размера `100 · scale`
(`· 1.5` для солнца), окрашенные своим прямым цветом; солнце получает
`DrawFlags 1` (рост краёв и туман в `satellite.vert`).
