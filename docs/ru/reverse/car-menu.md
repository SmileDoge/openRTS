# Меню вагона (Num3)

> Перевод [`docs/reverse/car-menu.md`](../../reverse/car-menu.md). Основной
> текст — английский: при расхождении верен он.

Состояние: статический анализ `rts1.exe` (IDA, декомпиляция), CONFIRMED,
если не отмечено иное:
- `0x4121BC`, `0x54E634` — обработчики ввода;
- `0x415A34` — выбор объекта;
- `0x462FC8` — построитель меню;
- `0x463F84` — обработчик действий.

Текстура меню — `menug.ace`; объект меню живёт в `0x61D6C4`.

## Открытие и закрытие

- **Открытие.** `VK_NUMPAD3` вызывает `0x415A34(99)`. Байт типа результата
  `+32` решает, что откроется:
  - 15 — действие у двери / посадки (`0x4210FC`; с Ctrl — режим 5);
  - 16 — сцепка: меню типа 1;
  - 17 — тележка: меню типа 2.

  Оба меню строятся через `0x462FC8(type, car, end)`. `end` — int16 в
  `+34`: 0 для конца или тележки к голове поезда, 1 — для задних. С
  клавиатуры меню встаёт в центр экрана; при `end` > 1 оно ставится у
  курсора.
- **Пока открыто:**
  - Вверх / Вниз двигают подсветку (`0x465C94`);
  - Enter или щелчок выбирают пункт (`0x463F84`);
  - Esc или Num3 закрывают меню.

  Обработанный пункт закрывает меню. «Сцепить» на движущемся поезде вместо
  этого делает себя серым.
- **Самозакрытие (`0x408574`):** меню сцепки поезда, который не
  принадлежит игроку, закрывается, когда камера дальше длины вагона + 5 м.

## Выбор объекта (`0x415A34`, аргумент 99)

Выбор работает только вне кабины: нет текущего локомотива или режим
`byte_61D394` равен 6 (пешком). Курсор не участвует. Берётся ближайшая
точка, проецирующаяся в область вида (`gluProject`), по всем вагонам:

- **Сцепка** — в координатах вагона `(0, 1, ±length/2)`:
  - в пределах 5 м от камеры;
  - вагон стоит (|v| < 0,1) или принадлежит поезду игрока или сцепленному с
    ним поезду;
  - поезда игрока типа ИИ пропускаются (в сетевой игре — только с флагом).

  Номер конца — `(Flags & 1) != 0` для +z и обратное для −z: перед модели —
  голова поезда, если вагон не развёрнут.
- **Тележка** — в координатах вагона `(0, 0, z)`:
  - z — первая / последняя тележка из списка тележек вагона (`+348` число,
    `+352` записи по 72 байта), иначе ±length/4;
  - в пределах удвоенного `+36` типа (ширина Size) от камеры;
  - не текущий локомотив;
  - |v| < 3 м/с или поезд игрока.

## Построение (`0x462FC8`)

Номера — те, по которым ветвится `0x463F84`. Стык сцепки — пара `[22]` =
передний вагон (его задний конец) и `[23]` = задний вагон (его передний
конец).

### Сцепка, оба вагона есть

| Номер | Пункт | Показывается, когда |
|---:|---|---|
| 1 | Расцепить | если не оба сцепных прибора типа 1 (жёсткая тяга) |
| 8 / 9 | Закрыть / Открыть концевые краны | Открыть, если оба крана закрыты (`+29` 0x80 / 0x40) |
| 2 / 3 | Разъединить / Соединить тормозную магистраль | Соединить, если хоть один рукав снят (`+29` 0x02 / 0x01) |
| 4 / 5 | Разъединить / Соединить питательную магистраль | оба `BrakeSystemType & 4`; биты 0x08 / 0x04 |
| 6 / 7 | Разъединить / Соединить кабель ЭПТ | оба `BrakeSystemType & 2`; биты 0x20 / 0x10 |
| 11 / 10 | Разъединить / Соединить кабель СМЕ | тип `+28` бит 2 у переднего вагона и бит 1 у заднего (пары меняются местами при развороте); соединён: `+30` 0x02 / 0x01 |
| 13 / 12 | Разъединить / Соединить высоковольтную шину | тип `+28` биты 8 / 4; `+30` 0x08 / 0x04 |

### Сцепка, свободный конец

| Номер | Пункт | Показывается, когда |
|---:|---|---|
| 16 | Сцепить | см. ниже |
| 9 / 8 | Открыть / Закрыть концевой кран | кран этого конца |
| 14 / 15 | Отпустить сцепку / Зафиксировать сцепку открытой | Отпустить, когда конец удерживается открытым (`+14` 1 передний / 2 задний) |
| 17 | Починить сцепку | `+14` 0x10 / 0x20: сломана |

«Сцепить» требует соседнего поезда у этого конца (поезд `+360` / `+364`,
зазор `+212` / `+276`). Пусть `r` — сумма сцепок `+28` (r0) обоих концов.
- Если зазор ≥ `r`, ничего не показывается.
- Оба поезда должны стоять.
- Если хотя бы один сцепной прибор не автоматический, типы должны совпадать.
- Если оба автоматические, один конец должен удерживаться открытым, а
  зазор должен быть ≤ 0,75 · `r`. Иначе они сцепляются сами при касании.

### Тележка (`end` 0 / 1 — передняя / задняя тележка)

| Номер | Пункт | Показывается, когда |
|---:|---|---|
| 9 / 10 | Вызвать событие посадки / высадки | только в задании |
| 1 / 2, 3 / 4 | Убрать / Поставить башмак | передняя / задняя тележка, `+31` 0x01 / 0x02 |
| 5 / 6 | Отпустить / Затянуть ручной тормоз | `HandbrakeValue` (`+112`) > 0,01; не на локомотиве с типом `+388 & 0x20` |
| 12 / 11 | Закрыть / Открыть отпускной клапан | `+32` 0x80 выставлен / `BrakeEquipmentType & 0xB` |
| 7 | Закрыть стоп-кран | `+32` 0x10 |
| 8 | Сведения о грузе | грузовой вагон с грузом |

Меню типа 3 — собственное меню задания; тип 4 — меню «Sim» (сервер,
трек-контроль, маневры).

## Действия (`0x463F84`)

Флаги вагона — dword в `+28` (Wagon Flags из `ts.h`), ставятся через
`0x4FED6C(car, mask, on)`. Звуки — дискретные триггеры на звуковых
источниках вагона:
- `0x4A8B54` на внешнем источнике `+376`, источнике кабины `+444+16` и
  источнике локомотива `+372+204`;
- `0x46AF1C` на всех них;
- `0x4A9DE8(source, 80, -1)` ставит переменный триггер 80, воздух.

**Сцепка (тип 1):**

| Номер | Действие | Флаги | Триггеры |
|---:|---|---|---|
| 1 | `0x469858(train, index of [23], 0, 0)`: расцепить, оставив краны как есть и сцепки не удерживаемыми открытыми | | |
| 2 | рукава тормозной магистрали сняты | 0x200 / 0x100 | 82, и 80 там, где кран этого конца открыт |
| 3 | рукава тормозной магистрали соединены | | 83, 81 |
| 4 / 5 | питательная магистраль снята / соединена | 0x800 / 0x400 | 82 / 83 |
| 6 / 7 | кабель ЭПТ снят / соединён | 0x2000 / 0x1000 | 84 / 85 |
| 8 | краны закрыты | 0x8000 / 0x4000 | 86, 81 |
| 9 | краны открыты | | 87, и 80 там, где рукав снят или конец свободен |
| 10 / 11 | кабель СМЕ соединён / снят | 0x20000 / 0x10000 | 89 / 88; затем `0x4F995C` перестраивает группы системы многих единиц (`+432` / `+396` каждого локомотива) |
| 12 / 13 | высоковольтная шина соединена / снята | 0x80000 / 0x40000 | 91 / 90; затем `0x4F9FB4` ставит концы шины каждого локомотива (`+436` / `+440`) |
| 14 / 15 | `0x4FF4B0(car, end, 0 / 1)`: отпустить / удерживать открытой | | 59 / 62 |
| 16 | сцепить (`0x469ED8`), сняв биты удержания открытой | | |
| 17 | начинает ремонт сцепки | `0x61D6D0` = вагон, со временем | |

Сетевая игра отправляет на сервер номера, кроме 1, 16 и 17 (`0x4CCA34`).

**Тележка (тип 2):**

| Номер | Действие | Флаги | Триггеры |
|---:|---|---|---|
| 1 / 2 | передний башмак убран / поставлен | 0x1000000 | |
| 3 / 4 | задний башмак убран / поставлен | 0x2000000 | |
| 5 / 6 | `HandbrakeValue` = 0 / 1 | | звук тормоза `+384` |
| 7 | стоп-кран закрыт | `+32` &= ~0x10 | |
| 8 | диалог груза | | |
| 9 / 10 | события задания | | |
| 11 / 12 | отпускной клапан открыт / закрыт | `+32` 0x80 | 92 / 93 |

Снятие башмака, отпуск ручного тормоза или открытие отпускного клапана на
поезде, который не принадлежит игроку, будит его (`0x5067A4(train, 3)`).

Что флаги делают в обновлении поезда — в `brakes.md`:
- экстренное: магистраль разряжается со скоростью 18 атм/с;
- отпускной клапан: цилиндр стравливается со скоростью 0,5 атм/с;
- каждая закреплённая тележка: 10 кН тормозной силы.

## Ремонт, груз, кабели (2026-11-04)

- **CONFIRMED** «Починить сцепку» (17) кладёт вагон в `0x61D6D0`, а
  `dword_61D5B4` (120 с, ставится при запуске в `0x403BF4`) — в
  `flt_61D6D4`; обновление поезда (`0x424488`) отсчитывает его, если не
  открыто меню типа 2 / 3, затем снимает биты `+14` 0x30 вагона. Пока он
  идёт, пункт серый (`+16` бит 0). Один ремонт за раз.
- **CONFIRMED** биты поломки ставит столкновение (`0x58A07C`): доля удара,
  приходящаяся на вагон (масса другого поезда к массе обоих), выше `Break`
  сцепки его конца (растяжение, `+104` / `+144` типа) ставит `+14` 0x10
  (передний) или 0x20 (задний) через `0x4FF4B0`.
- **CONFIRMED** «Сведения о грузе» (8) требуют вагон `+326` (число
  единиц груза) и `+31` типа = 2; `0x502680` выводит текст `0x50BC20`
  (груз и масса каждой единицы, затем итог вагона) сообщением на 30 с.
- **CONFIRMED** расцепка (`0x469858`) разъединяет кабели в месте расцепа
  (`0xA0000` снимается с последнего вагона передней части, `0x50000` — с
  первого вагона отцепа); сцепка (`0x469ED8`) только перегруппировывает
  (`0x4F9FB4`, `0x4F995C`).
- В openRTS есть каждый пункт (`docs/train-systems.md`); груз берётся из
  записей `FreightAnim` состава.
