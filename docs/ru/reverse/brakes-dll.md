# Brakes.dll (вспомогательная библиотека MaDaDev)

> Перевод [`docs/reverse/brakes-dll.md`](../../reverse/brakes-dll.md).
> Основной текст — английский: при расхождении верен он.

Нулевой шаг `docs/brakes-dll-replacement.md`: что это за библиотека,
какими объектами и вызовами она пользуется, её стек переменных и как DLL
локомотивов в него читают и пишут. Её кода в openRTS нет; здесь только
смещения и поведение.

**Источники** (2026-11-18). IDA 9.0 с Hex-Rays, без интерфейса
(`tools/reverse/`), на копиях из установки:
- `mdd_Libraries/Brakes/Brakes.dll`, 337 408 байт;
- 34 DLL, которые ищут её по имени (§5).

**Статусы:**
- ПОДТВЕРЖДЕНО: прочитано в коде;
- ВЕРОЯТНО: по коду и именам параметров, в работе не видели;
- НЕИЗВЕСТНО.

Имена вида `sub_4033D0` — от IDA. `updateKLUB`, `SwitchKLUB` и экспорты —
собственные имена DLL (Borland, с символами).

## 1. Интерфейс (ПОДТВЕРЖДЕНО)

- **Экспорты:**

## 5. DLL локомотивов лезут в неё (ПОДТВЕРЖДЕНО)

В 36 DLL установки есть UTF-16 имя `BRAKES`. Кроме самой Brakes.dll здесь
разобраны 34. Каждая находит её через
`RTSGetLocoObjectByName(lib, loco, 22, L"BRAKES", -1)` (или у ведомого —
для других вагонов своей секции) и идёт в её стек переменных.

**`var + 32` — их слово обмена.** Входы (DLL поезда ставит их до `Run`
Brakes.dll; Brakes.dll снимает `0x10` .. `0x8000` в конце своего `Run`,
так что они живут один шаг):

| Бит | Кто ставит | Значение |
|---|---|---|
| `0x4` | почти все, по своим переключателям (ВЛ80Т: переключатели кабины 30, 31 = 2 и 83); и `updateKLUB` — по `KLUB_PIT` | ВЕРОЯТНО: приборы безопасности под питанием |
| `0x10`, `0x20` | ЭД2Т, ЭД4М(new), ЭД9М, ЭП2Д, ЭР9П, ЭР9Т | ЭПТ: перекрыша, торможение. Давление ЭПТ строится в `var + 40`, до 4,3 атм, с темпами `var + 236` / `var + 232` (ПОДТВЕРЖДЕНО) |
| `0x40` | они же, ЧС7, 2ЭС6 | НЕИЗВЕСТНО (ЭПТ) |
| `0x100` | 2ТЭ10, 2ТЭ10Л, 2ТЭ10У | её триггеры в звуки локомотива (§1) |
| `0x200`, `0x400` | ВЛ10, ЭП2К, ВЛ85, 2ЭС6; `0x400` ещё ЭП1М, 2ЭС4К | НЕИЗВЕСТНО |
| `0x1000`, `0x2000` | ВЛ85 | НЕИЗВЕСТНО |
| `0x4000`, `0x8000` | 2ЭС6 | НЕИЗВЕСТНО |

Выходы (ставит Brakes.dll; DLL поезда проверяют их, чаще всего чтобы
снять тягу: «биты 1, 2 или 8», 2ТЭ10 ещё «бит 4 снят»):

| Бит | Кто ставит | Значение (ПОДТВЕРЖДЕНО, где разобрано) |
|---|---|---|
| `0x1` | `_Run` | ЭПК сработал: бдительность не подтверждена, ТМ выпущена (`TrainPipeRate` −1,2) |
| `0x2` | `_Run` | датчик 418 (`BR_418PID` включён): ТМ падает быстрее 0,0125 атм/с дольше 0,5 с без ЭПТ; снимается, когда ТЦ вагона выше 0,3 атм или 418 выключен |
| `0x8` | САУТ (`0x4033D0`) | торможение САУТ |
| `0x4` | `updateKLUB` | см. выше |

**Другие смещения, которые они используют:**
- **ЭП2К:** читает `var + 40` (давление ЭПТ выше 0,3 — торможение); пишет
  `var + 312` = 2,0.
- **ВЛ10:** пишет в `var + 312` 1,3. **ВЛ85:** 2,0. **2ЭС6:** 2,5.
  Значение НЕИЗВЕСТНО.
- **ЭП20, ЭП2Д:** читают `var + 116`, `+120`, `+140` (следующая цель КЛУБ,
  расстояние до неё, допустимая скорость) для своих экранов. ЭП2Д ещё
  читает `+164`, `+168`, `+224`.
- **ЭП20:** пишет `var + 296`.
- **ЭП1М:** читает `+144`, `+256`, `+308` и бит `0x400` в `+8`. **ЭП2К,
  2ЭС6:** читают `+256`, `+308`.
- **ЭП20, ЭП2К, ЭР9П, ВЛ10:** проверяют бит `0x01000000` в `var + 4`
  (Brakes.dll работает, §6). **USAVPL:** бит `0x800` в `var + 4`.
- **ЭП2Д:** читает `var + 224` (пройденный путь).
- **ТЭП70:** пишет `var + 20` и `+24` (0 или 45,0: таймер бдительности).
- **RTSConnector** (связь MaDaDev со своими программами) читает `+4` ..
  `+244` и пишет `+280`. Игре не нужен.

## 8. Открыто

- **Внутри `_Run`:** тормоза по системам: прочитаны в §10 (шаг 2).
- **КЛУБ** (§11): экран БЛОК (`PB_SETUP` 8), собственная логика ТСКБМ
  (`0x40EAA8`), САУТ (`0x4033D0`), куда `0x406540` пишет данные поезда.
- **Биты DLL поездов** `0x40` .. `0x8000` и `var + 312`.
- **Что ещё** DLL поездов читают в `Engine` из того, что записала
  Brakes.dll.

## 9. Эталонные прогоны (первый шаг, 2026-11-18)

**Запись.** `openrts-train-check <корень> --dll ... --script <файл>
--record <файл.tsv>` пишет каждый шаг (20 в секунду). Для каждого вагона с
библиотекой (`--record-library`, по умолчанию `BRAKES`) — строка:
- воздух вагона;
- тормозные выходы его `Engine`;
- триггеры SMS библиотеки и локомотива;
- переключатели кабины, которые изменились;
- весь стек переменных библиотеки сырыми 32-битными словами.

Хост отдаёт стек только по запросу (`StepRequest::want_aux_vars`, протокол
13), в игре — никогда.

`tools/reverse/golden_report.py` рассказывает запись по фазам: воздух в
начале и конце каждого хода, звуки библиотеки, выбранные переменные при
изменении.

Записи делаются из установки и в репозиторий не попадают; сценарии лежат в
`tests/data/golden/`:
- **`ed9m_brakes.script`:** шестивагонный ЭД9М, 430 с, тумблер ЭПТ
  (переключатель 35, `ZT_09`, клавиша T) включён:
  - 395 по положениям, экстренное;
  - трогание с ответом на запрос КЛУБ, потом превышение без ответа;
  - ключ ЭПК «выкл.» и «вкл.».
- **`ep20_brakes.script`:** ЭП20 под 3 кВ постоянного тока, 300 с:
  - кран 130 по положениям (вторая кабина);
  - 224 по положениям;
  - ключ ЭПК.

**Что они показывают** (воздух RTS; ПОДТВЕРЖДЕНО замером):

| | ЭД9М | ЭП20 |
|---|---|---|
| зарядное давление (УР во II) | 4,499 (`BR_ZARPRESS` 4,6) | 4,999 (5,1): ВЕРОЯТНО `BR_ZARPRESS` − 0,1 |
| V: УР | −0,22 атм/с | −0,22 атм/с |
| V: `TrainPipeRate` | −0,25 | −0,21 |
| III, IV | ТМ опускается до УР и держится | так же |
| II после ступени | УР снова 4,49 через 7,0 с | 7,3 с |
| VЭ | ЭПТ (ниже), УР −0,03 атм/с, как Va | без ЭПТ: УР −0,03 атм/с; `EPTValue` остаётся −1 |
| VI | `TrainPipeRate` −1,2 | −1,2 |
| I | УР +0,18 атм/с, до 5,39 | |
| 224, положения 0..4 | | `IndependentBrakeValue` 4, 3, 2, 1, 0 атм; положение 5 пружинит обратно в 4 |

**ЭПТ** (ЭД9М, тумблер включён; ПОДТВЕРЖДЕНО замером):
- `BrakeSystemsEngaged` равен 3 (ТМ и ЭПТ).
- В V, VЭ и VI давление ЭПТ каждого вагона (`var + 40`) растёт; в III и IV
  держится; II и I его выпускают.
- **Темпы.** Растёт примерно на 1,0 атм/с, падает на 0,65 атм/с (2,85 до
  0 за 4,4 с).
- **У каждого вагона свой темп.** За одни и те же 2,75 с в V шесть
  вагонов встали на 2,73 .. 3,06 атм (0,99 .. 1,11 атм/с). ВЕРОЯТНО: её
  темпы `var + 236` / `+232`, заданные в `_Init`, разыгрываются по
  вагонам.
- **Куда идёт.** У ЭД9М `BR_MODE` равен 1, поэтому давление идёт в
  `IndependentBrakeValue`, и RTS ведёт за ним вспомогательный ТЦ вагона.
- Без тумблера VЭ — только Va, а `EPTValue` остаётся −1.

**Бдительность КЛУБ** (ЭД9М, тестовый путь: сигналов нет):
- **Трогание.** Через 0,7 с после начала движения запрос (бит 8 в
  `var + 8`) и свисток (56). РБ (переключатель 23) отвечает: свисток
  выкл. (57), его звуки 3199 и 901 / 902.
- **Перед превышением.** За 2 км/ч до допустимой скорости ставится
  `0x800000` (предупреждение, 3199).
- **Выше неё.** Мигание (`0x400000`, каждые 0,55 с) и запрос. Без ответа
  через 7,05 с после запроса срабатывает ЭПК:
  - `0x400` в `var + 4`, `0x01000000` в `var + 8`, бит 1 в `var + 32`;
  - `TrainPipeRate` −1,2, звук 130;
  - ТМ пустеет, поезд встаёт.
- **Восстановление.** Ключ ЭПК «выкл.» сразу снимает срыв, ТМ заряжается.
  После «вкл.» КЛУБ примерно через 3 с снова спрашивает (ручка в I), и на
  этот запрос тоже надо ответить.

**Звуки, которые встретились:**
- 917 / 918 / 919: ход ручек 395, 130 и 224;
- 120 .. 137 (31xx у ЭП20): воздух и лампы;
- 3196, 3198: КЛУБ под питанием;
- 903: ключ ЭПК.

**Открыто по этим прогонам:**
- **Контроллер ЭД9М ниже нуля** (положения 0..5) ничего не даёт в `var +
  32`, а после него поезд не берёт тягу: что они значат — дело ed9m.dll,
  не разобрано.
- **Под 25 кВ переменного тока** ЭП20, запущенный «включённым» (схема на
  постоянный ток), в течение 2 с отключает ГВ, и компрессоры встают (в
  первой записи ГР упал с 7,0 до 4,3 атм). Сценарий даёт ему 3 кВ
  постоянного: ГР тогда ходит между 7,8 и 8,8 атм.

## 11. КЛУБ-У (шаг 3.1, 2026-11-19)

Прочитано в `_ALSN` (`0x402828`), `updateKLUB` (`0x406658`), `SwitchKLUB`
(`0x40D52C`), в части `_Run` про КЛУБ («EPK KLUB») и в `Switched`
(`0x4239C0`). CONFIRMED, если не сказано иное. Скорости в км/ч,
расстояния в м.

### Что его включает

- **`PB_SETUP`** (у ЭД9М 7) выбирает приборы. Бит 1: САУТ (`0x4033D0`).
  Бит 2: КЛУБ (`updateKLUB` и часть `_Run` про ЭПК). Бит 4: ТСКБМ
  (`0x40EAA8`) и периодическая проверка бдительности КЛУБ. Бит 8: экраны
  и звуки БЛОК (3195 / 3196 вместо 3199 / 3198, `BLOCK_MODE`). У ЭД9М
  КЛУБ-У без БЛОК. Без бита 2 КЛУБ не работает совсем: ни `updateKLUB`,
  ни `SwitchKLUB` (из `_CanSwitch`), ни часть `_Run` про ЭПК, ни сигнал
  РБ; `_ALSN` и задержка АЛСН работают (так КЛУБ openRTS выключает КЛУБ
  Brakes.dll, шаг 3.4).
- **Питание** (`0x402658`): включены все выключатели `KLUB_PIT1 ..
  KLUB_PIT<KLUB_PCOUNT>` (у ЭД9М 58 и 59). Без питания нет допустимой
  скорости и экранов, а при включённом ключе ЭПК таймер бдительности
  держится не ниже 5 с, так что ЭПК срывает через 7 с.
- **Ключ ЭПК** (`PB_EPKKEY`) пишет своё состояние в `Engine::ALSNOn`
  (`+106`). Часть `_Run` про ЭПК и строки экрана о светофоре работают
  только с ним.
- **Считается только рабочая кабина** (её 367 в `BR_367OPPOL`, или
  `BR_NUMCABS` 1); экран другой кабины гасится.
- **Когда что происходит за шаг** (проверено шаг в шаг на эталонных
  прогонах, шаг 3.3):
  - клавиши срабатывают в момент нажатия: `_CanSwitch` вызывает
    `SwitchKLUB` при переходе в состояние не 0, если КЛУБ запитан;
  - РБ, РБС и ключ ЭПК срабатывают в `Switched`, при любом движении,
    после `Run` этого шага (RTS двигает выключатели кабины после `Run`
    DLL);
  - `Run` видит выключатели (питание, `ALSNOn` ключа ЭПК) такими, какими
    они были до движений этого шага.
- **ТСКБМ** (`0x40EAA8`, выключатель `TSKBM_SW`, у ЭД9М выключен), пока
  включён, ставит `var + 4` бит 8: периодическая проверка бдительности
  КЛУБ останавливается; его собственный таймер — `+12`.
- **`_Init`:**
  - показание зелёное (7);
  - включён поездной режим (`var + 8` `0x400`);
  - скорость на белый 40 (`+148`);
  - показ времени выключен (`+208` −1).

### Светофор (`_ALSN`, каждый шаг до `Run`)

- **Какой светофор.** Массив по направлению движения: впереди, или
  сзади, когда кабина (`PB_FLIP`, `BR_254DID1`, реверсор) едет в другую
  сторону. Цель — первый светофорный объект с NORMAL головой (флаг 1).
  Его `Aspect[0]` — показание кабины (`Cabin::Signal +112`), расстояние
  `+108`, его ограничение `+132` (м/с), данные `+136`.
- **Без кодов:**
  - показание 8, когда светофор за препятствием (флаг `0x10`);
  - показание 8, когда впереди локомотива по направлению движения есть
    вагоны (`RTSGetInteger` 2 и 4 с направлением): коды получает только
    ведущий локомотив.
- **Показание 0 (стоп) или 8.** Становится 2 (Б) с 40 км/ч (11,12 м/с) и
  флагом `0x20`, если прошлое показание не было 1 (`var + 4` `0x100000`,
  ставится, пока оно 1). После КЖ красный остаётся.
- **DISTANCE голова** (флаг 2) в 2 (restricting) до первой нормальной:
  тоже Б с 40 и флагом `0x20` (`var + 4` `0x200000`).
- **Показание 1 (КЖ):**
  - ограничение светофора 0;
  - ограничение КЛУБ не выше 63.
- **Показания 3 .. 5** без своего ограничения: 60 км/ч (16,667 м/с).
- **Счёт АЛС-ЕН** (`+244`), с таблицей команды 137 (`+240` 1..4): первый
  нормальный светофор и следующие за ним подряд в 6 или 7, не больше 4.

**Ограничения:**
- `+80` = |limit| × 3,6: наименьшее из ограничений поезда, которое даёт
  RTS.
- **`+336`, своё ограничение.** Ставится в ограничение поезда, когда
  светофор ближе 5 м (проследован), а ограничение выше. У знака скорости
  ближе 5 м ставится в следующее ограничение. Сбрасывается, когда
  ограничение поезда его превысит. Пока стоит, `+80` равно ему. Более
  низкое ограничение светофора не снижает ограничения КЛУБ: снижают
  только знаки скорости и показания.
- **Следующее ограничение** `+116` = |x| × 3,6 на `+120` = y (нет: `+80`
  на 100 000 м).
- **Ограничение светофора вместо него.** Ограничение светофора (если
  ≥ 0) на его расстоянии занимает место следующего ограничения, когда:
  - светофор ближе знака, или
  - (d_светофора − d_знака) × 0,08 < v_знака − v_светофора.

  `+116` не больше 255.
- `+84` = расстояние до светофора − 50 (0 дальше 9999); `+144` — его целые
  метры; `+88` `0x4000`, когда ограничение светофора 0.

### `_Run` перед КЛУБ

- **`ALSN_DELAY`** (у ЭД9М 5 с). Новое показание или новый счёт АЛС-ЕН
  принимается, только когда простоит столько. Пока кабина показывает
  последнее принятое (`+72` / `+248`, таймер `+68`). `_Init` ставит
  таймер в саму задержку, поэтому первая смена принимается через шаг.

  С приёмом заново начинается отсчёт пути после жёлтого (`+332`, ниже).
- **Б после КЖ — это К.** Принятое 2 после 1 (`+64`) показывается как 0.

### Допустимая скорость (`updateKLUB`, каждый шаг)

**Повышение ограничения ждёт поезд.** Когда `+80` поднимается выше
последнего принятого `+192`, а длина в вагонах введена (`+176`):
- старое ограничение держится, пока поезд не пройдёт `+176` × 14 м
  (`BR_EPT` 0) или × 25 м (`BR_EPT` 1);
- путь считается в `+188`;
- всё это время стоит `+88` `0x40000`;
- при отпускании звучит сигнал.

`KLUB_GRSPD` (у ЭД9М 120) ограничивает сверху.

**Без ЭК** (номер пути не введён, `+160` & 0x7F = 0, «РЕЖИМ БЕЗ ЭК»):
ограничения маршрута не используются. `+80` = `KLUB_GRSPD`, и:

| Показание | Цель (`+116` на `+120`) |
|---|---|
| 3 .. 5 (Ж) | `KLUB_YLSPD` (60) на `KLUB_BLUCH` (1000) − путь, пройденный с появления показания (`+332`, не больше `KLUB_BLUCH`) |
| 1 (КЖ) | 20 на том же |
| остальные | `KLUB_GRSPD` на 10 000; `+332` = 0 |

**Кривая** прямая: 0,08 км/ч на метр, 12,5 м на км/ч.

| Случай | `+140`, допустимая скорость |
|---|---|
| К или КЖ, с питанием, с ЭК | `+80`, если (int)`+80` × 12,5 ≤ целых метров до светофора (`+144`); иначе 0,08 × `+144`, один сигнал (`+128` бит 2) |
| иначе, с питанием | `+80`, если L ≤ `+116`, или (int)(L − `+116`) × 12,5 ≤ `+120`, или (флаг `0x20` и `+116` ≤ 0), где L = 40 с флагом `0x20`, иначе `+80`; иначе `+116` + 0,08 × `+120`, один сигнал |

Потом по порядку:

1. **КЖ:** ограничение светофора 0, `+140` не выше 60.
2. **Не ниже 10.**
3. **Разрешение 20 км/ч** (`var + 8` `0x1000`). Сбрасывается на

4. **Разрешение на белый** (`var + 8` `0x2000000`), на К (0, 8): Б с 40.
   Сбрасывается на любом другом показании.
5. **`var + 8` `0x10000000`** стоит, пока скорость выше `+140`, какой
   она получилась здесь, до правил ниже. Пока он стоит, РБ не отвечает
   (эталонный прогон: на Б после последнего светофора знак 15 держит его
   и под 43 от Б, и периодический запрос срывает ЭПК).
6. **Команды 799 / 809.**
   - Команда 799 (`var + 8` `0x40`): Б со скоростью на белый (`+148`).
   - Команда 809 (`0x80`) на Б: та же скорость.
7. **Маневровый режим** (`var + 8` `0x400` снят): Б с 60.
8. **САУТ** (`PB_SETUP` 1, САУТ включена: `var + 4` `0x40`).
   - Её допустимая (`+256`) + 5, если ниже, заменяет `+140`; на экране
     «С».
   - На БЛОК − 3, с надписью «САУТ».

   Действует в поездном режиме, если не стоят команда 799 или 809 на Б.

### Бдительность и ЭПК

**Запросы** (`var + 8` бит 8, таймер `+24` не меньше 4,9 с):

- **Выше допустимой.**
  - Когда: (int)`+140` − целая скорость < 0, при перерисовке экрана
    (каждые 0,5 с; на БЛОК 0,33).
  - Не в первые 10 с боксования (`Engine::wheelslip`, таймер `+216`) и
    не в двойной тяге (`0x800`).
  - Ещё ставит `0x400000`: мигание.
  - Зона перед ней, при перерисовке:
    - в пределах 3 от `+140` скорость мигает;
    - в пределах 2 ставится `0x800000`, и каждые 0,5 с звучит сигнал
      (3199), пока скорость не выше `+140`.
- **Движение на К** (0, или 8 выше 1 км/ч; не в двойной тяге) выше
  0,5 км/ч: запрос каждый шаг и `var + 4` `0x400` («СРЫВ ЭПК КОН»).
  - Пока стоит `0x400`, РБ на ходу не отвечает, и ЭПК срывает примерно
    через 7 с.
  - После стоянки на КЖ ближе 200 м до светофора (`0x80000`, ниже)
    первые 20 км/ч свободны: красный проследован после остановки.
- **КЖ:**
  - стоянка ближе 200 м до светофора ставит `0x80000`;
  - выше 1,5 км/ч запрос, один раз за трогание (`+128` бит 4).
- **Б** (не в маневровом режиме, не при 799 или 809, не в двойной тяге):
  - скорость в момент появления запоминается (`+196`);
  - допустимая падает от неё + 5 на 0,02 км/ч за метр пути (`+200`), не
    ниже 43;
  - выше 1,5 км/ч один запрос (`+128` бит `0x20`; на БЛОК только без
    САУТ).
- **Смена показания** (часть `_Run` про ЭПК, `+48` — прошлое).
  - Сигнал 3198.
  - На 0, 1, 2 или 8 выше 1 м/с: запрос с таймером 4,95 с.

    Поэтому свисток сразу, а ЭПК через 7 с.
  - Новый счёт АЛС-ЕН тоже даёт сигнал.
- **Периодическая** (`PB_SETUP` 4), в движении выше 0,1 м/с.
  - Таймер `+152`: запрос через 90 с на Б или зелёном (2, 6, 7), через
    40 с на остальных.
  - РБ, ключ ЭПК и смена показания сбрасывают его в 0.

**Таймер** `+24` идёт, пока стоит бит 8, или без питания при включённом
ключе ЭПК:
- на 5 с свисток, звук 56 (на БЛОК 3956);
- на 12 с ЭПК:
  - таймер 45;
  - `var + 4` `0x400`, `var + 8` `0x01000000`;
  - `TrainPipeRate` −1,2, `EPTValue` −1;
  - `var + 32` бит 1.

  Остаётся сорванным, пока не выключат ключ ЭПК.

**Ответы:**
- **РБ** (`PB_RB`; таймер меньше 12, питание есть; не выше допустимой,
  `0x10000000`, и нет `0x10` ТСКБМ; на стоянке, или нет КОН `0x400`).
  Поэтому выше допустимой помогает только торможение: ЭПК срывает через
  7 с после первого запроса (эталонный прогон, шаг 3.2).
  Она:
  - снимает бит 8 и таймеры;
  - свисток выключается (57), если был больше 5;
  - сигнал 3199.
- **РБС** (`PB_RBS`): то же, без условий КОН и ТСКБМ, и снимает `0x10`
  ТСКБМ.
- **Ключ ЭПК выключен:**
  - снимает запрос и таймеры;
  - 57, если таймер был больше 5;
  - `ALSNOn` 0.

  Снова включён: сигнал 3198.
- **КОН.** Движение с выключенным ключом ЭПК (`ALSNOn` 0) при питании и
  цилиндрах ниже 0,7 атм (Wagon `+52`, `+96`):
  - через 10 с (`+16`) ЭПК срывает;
  - `var + 4` `0x200`;
  - таймер 45.

### Клавиши (`SwitchKLUB`, `KLUB_B*ID<кабина>`; каждая даёт 3197 и 3199; отказ ВВОД — 3198)

| Клавиша | Что делает |
|---|---|
| `B0` .. `B9` | цифра в ввод `+132` (× 10 + d); после открытия поля (`var + 8` `0x4000000`) первая цифра начинает его заново |
| `BPL` / `BMN` | `+132` + 1 / − 1; `BSB` ставит 0 |
| `BK` (К) | режим команд вкл / выкл (`var + 8` бит 1), ввод 0 |
| `BVV` (ВВОД) | принимает ввод: команду в режиме команд, иначе открытое поле (ниже) |
| `BP` (П) | поле номера пути (`0x8000`) |
| `BL` | на стоянке: данные поезда, поле за полем (`+184` 1 .. 5) |
| `BVK` (ВК) | снимает разрешение 20 км/ч; потом на стоянке на КЖ даёт его (`0x1000`); на стоянке на К (0, 8) с нажатой РБ — разрешение на белый (`0x2000000`) |
| `BMP` (МП) | снимает двойную тягу (`0x800`, `0x100000`); потом на стоянке с нажатой РБ в поездном режиме включает её; иначе на стоянке на Б переключает поездной / маневровый режим (`0x400`) |

**Поля** (ВВОД принимает `+132`):
- **Номер пути.**
  - `+160` = ввод, не больше 127; 0 — нет номера.
  - Затем «ПРИЗН. ПРАВ.» (`0x10000`): ненулевой ввод ставит `+160`
    `0x80`, правильный путь («ПР»), 0 — неправильный («НП»).
- **Данные поезда** (`BL`, `+184`): номер машиниста (`+164`), номер
  поезда (`+168`), длина в осях (`+172`), в вагонах (`+176`), масса
  (`+180`). Каждое поле начинается с прошлого значения. После массы
  `0x406540` их выписывает (UNKNOWN куда; больше их никто не читает).
- **Скорость на белый** (799, 809): `+148`.
- **Таблица АЛС-ЕН** (137): `+240` = 0 .. 4.
- Если `KLUB_KASS` задан, а его выключатель в 0 (нет кассеты),
  подтверждение — сигнал отказа (3198); значение всё равно принимается.

### Номер пути и карта

У КЛУБ в Brakes.dll нет своей карты и нет номеров путей маршрута.
- **Номер не выбирает путь.** Номер, введённый машинистом (1 .. 127),
  включает режим «ЭК» и показывается с ПР / НП. Сам номер ничего не
  выбирает.
- **С любым номером** КЛУБ берёт то, что RTS даёт через `ALSN` по
  маршруту, который поезд пройдёт (по стрелкам, как они стоят):
  - ограничение поезда и следующего знака;
  - показание, расстояние и ограничение следующего светофора.
- **Без номера** держится `KLUB_GRSPD` и показания, а после жёлтого / КЖ
  — `KLUB_YLSPD` / 20 км/ч на `KLUB_BLUCH` метрах.
- **`RTSGetTrackItems`** нужен только экрану: имя станции, платформы,
  переезды и значения знаков скорости.
- **Поэтому openRTS номера путей не нужны**, чтобы сделать то же самое:
  хватает его прохода светофоров и ограничений по заданному маршруту.
