# Инспектор

Состояние: первая версия (2026-11-08). Основа для правки контента прямо в
игре: дальше — редактор поезда и кабины.

F12 открывает два окна:

- **Объекты карты:** дерево того, что загружено вокруг камеры.
  - *Мир:* тайлы мира (3 x 3 вокруг камеры), в каждом его объекты
    (статические объекты, путь, опоры КС, светофоры, знаки скорости,
    текстуры на земле, леса, переезды, экипировка, дорожное движение), по
    виду и имени модели.
  - *Поезда:* каждый поезд, его вагоны по порядку.
  - Фильтр по имени; «Выбирать щелчком в мире»: щелчок в сцене тогда
    выбирает объект под курсором (по габариту его модели, ближайший;
    габарит, внутри которого глаз, — только если больше ничего на пути
    нет), а не работает органом управления. Двойной щелчок в дереве —
    перейти к объекту.
- **Свойства** выбранного объекта, его габарит рисуется в сцене:
  - у объекта мира: вид, UiD, тайл мира, положение, флаги столкновения и
    статики; у вагона: его поезд и место, `.eng` / `.wag`, масса, размер,
    DLL;
  - его модель, откуда она берётся (источник VFS: папка контента, пак или
    мод) и откуда её переопределение, габарит модели и уровни детализации;
  - «Перейти»: свободная камера рядом с объектом, смотрит на него;
  - **Материалы:** состояния примитивов модели; части с одинаковыми
    текстурой, шейдером и материалом света — одна строка с их числом, первым
    и последним номером (сто анимированных частей на четырёх текстурах
    раньше давали 301 строку); над таблицей — число текстур и частей.

## FullBright как обычный, по моделям

Поверхности FullBright из MSTS (материал света -8) не освещаются ни солнцем,
ни фонарями. Галочка панели «Освещать FullBright как обычные» освещает их
все; платформу, нарисованную FullBright, лучше освещать как обычную, а
вывеску или стекло фонаря — нет. В инспекторе у материала FullBright есть
галочка «Как обычный»: изменение видно сразу (модель перезагружается),
«Сохранить в мод» его сохраняет.

- Сохраняется как `MODS_OPENRTS/<мод>/<путь модели>.openrts`, например
  `MODS_OPENRTS/openrts_edits/ROUTES/Kuban_RTS/SHAPES/Platform.s.openrts`
  (имя мода в окне, запоминается; сначала `openrts_edits`). Модель и папки
  контента не трогаются; RTS этот файл не видит.
- Мод, которого ещё нет в `openrts.ini`, добавляется в его `[Mods]` (после
  остальных): VFS подключит его со следующего запуска; в этом запуске
  изменение держится в памяти.
- «Отменить изменения» отбрасывает несохранённое (снова действует
  переопределение из файла, если оно есть). Если снять все галочки,
  сохранение удаляет файл.

### Файл

```text
OpenRTSShapeOverride ( 1
	PrimState ( 12 Image ( "platform.ace" ) LightMaterial ( -5 ) )
)
```

- `PrimState ( номер ...)`: номер состояния примитива в модели.
- `Image`: имя файла картинки его текстуры, в нижнем регистре: проверка;
  модель, заменённая с тех пор, чьё состояние больше не рисует эту
  картинку, остаётся как есть.
- `LightMaterial`: материал света MSTS (-5 обычный, -6 / -7 блестящий, -8
  FullBright, -9 по окружности, -11 полуяркий, -12 тёмный).
- Загрузчик моделей (`renderer::load_model_asset`) применяет его после
  разбора модели: состояние получает собственное состояние вершин — копию
  того, которое оно делило, с этим материалом света, так что остальные
  сохраняют своё (`formats::apply_shape_override`). Файл переопределения —
  одна из зависимостей модели: если он изменился в подключённом моде,
  модель перезагружается.

## Код

`viewer/src/inspector.*` (окна, выбор, габарит, сохранение),
`formats/shape_override.*` (файл), `renderer::find_shape_override` /
`hold_shape_override` (файл или удерживаемое на запуск),
`RenderModel::primitives()` / `ModelBounds::min` / `max` (что инспектор
показывает и по чему выбирает), `TrainView::inspected_cars`. Опция захвата
`--capture-inspect` открывает его и щёлкает в середину кадра; захват
печатает выбор.
