# Скрипты на Luau

Свои модули openRTS можно писать на [Luau](https://luau.org) — это Lua 5.1
с типами и несколькими добавками (`+=`, `continue`, выражения
`if … then … else`). Первый такой модуль — воздухораспределитель (ВР)
реалистичного воздуха; плагины поездов потом будут на том же языке
(`roadmap.md`, «Плагины на Lua»).

Код: `script/` (виртуальная машина), `simulation/src/distributor.cpp` (ВР),
`tools/brake-stand` (стенд), `sdk/luau/` (примеры).

## Песочница

Каждый скрипт работает в своей виртуальной машине:
- только собственные библиотеки Luau, они безопасны: `math`, `string`,
  `table`, `bit32`, `utf8`, `buffer`, `vector`, `coroutine`, `debug`
  (только `info` и `traceback`), `os` (только время: `clock`, `time`,
  `date`). Нет `io`, файлов, процессов, `require` пока тоже нет;
- глобальные имена библиотек заморожены, свои глобальные имена скрипта
  лежат в отдельной таблице;
- у каждого вызова предел времени (200 мс): бесконечный цикл останавливается
  с ошибкой, а не вешает игру;
- в ошибке есть файл и строка (`vr292.luau:12: …`). Игра пишет её в свою
  консоль (`openrts.log`, когда игру запускает меню) — один раз на скрипт
  и ошибку, и вагон дальше работает со встроенным ВР.

## Воздухораспределитель (ВР)

**Подключение.** В `.wag` или `.eng`, внутри `Wagon ( … )`:

```
ORTSBrakeDistributor ( "my_vr.luau" )
```

Файл лежит рядом с `.wag` / `.eng`. Работает с моделью реалистичного
воздуха (окно «Поезд», «Реалистичный воздух (openRTS)»), а её поезд
использует, пока ни у одного его локомотива нет DLL RTS: краны этих DLL
подогнаны под ВР самой RTS.

**Что даёт скрипт.** Глобальную функцию `step(c, dt)`. Модель вызывает её
на каждом подшаге (в игре меньше 2 мс, на стенде 3,3 мс) для вагона, с
таблицей вагона `c` и длиной подшага `dt` в секундах. Вызов скрипта вроде
примера стоит намного меньше микросекунды. Скрипт читает и меняет
таблицу:

| Поле | | Что |
|---|---|---|
| `pipe` | чтение, запись | ТМ у вагона, атм. Понизить — взять воздух из магистрали (зарядка, дополнительная разрядка) |
| `rate` | чтение | как быстро меняется ТМ, атм/с |
| `zr` | чтение, запись | ЗР, атм |
| `tc` | чтение, запись | ТЦ, атм |
| `ref` | чтение, запись | уровень, который надо помнить (483: его РК; 292: ЗР в начале торможения) |
| `braking` | чтение, запись | положение ВР: тормозное (торможение или перекрыша), а не отпускное. Игра его только хранит между шагами; сила тормоза берётся из `tc` |
| `emergency` | чтение, запись | до вагона дошла волна экстренного торможения; поставить — начать волну здесь |
| `ep` | чтение | цель ЭПТ, атм (< 0: нет) |
| `ep_wired` | чтение | у вагона есть ЭПТ |
| `tc_max` | чтение | ТЦ полного торможения (483: по загрузке) |
| `ratio` | чтение | `TripleValveRatio` |
| `v_pipe`, `v_zr`, `v_tc` | чтение | объёмы магистрали у вагона, ЗР и ТЦ, м³ |
| `mass` | чтение | масса вагона, кг |
| `kind` | чтение | какой встроенный ВР был бы у вагона: `"292"`, `"483"`, `"305"` |
| `load` | чтение | режим загрузки 483: `"empty"` (порожний), `"medium"` (средний), `"loaded"` (гружёный); ставится в меню вагона, пока не поставлен — по массе |
| `mountain` | чтение | горный режим 483 (меню вагона) |
| `plug` | чтение | пробка 292: `"short"` (К), `"long"` (Д), `"no_accelerator"` (УВ) (меню вагона) |
| `state` | ваша | таблица, которая сохраняется между шагами, для всего остального |

Давления берутся обратно как числа не ниже 0; всё другое пропускается.
Течение воздуха по магистрали между вагонами, кран машиниста и волна
экстренного торможения остаются за моделью.

**Пример.** `sdk/luau/vr292.luau` — встроенный ВР 292, переписанный на
Luau построчно (тест `openrts.distributor` проверяет, что он даёт те же ТЦ
и ЗР, что и C++). Начинайте с него.

## Стенд

`openrts-brake-stand` прогоняет ВР по постоянной программе, как стенд со
своим краном машиниста: давление в магистрали держится по программе, а
ответ ВР измеряется.

```
openrts-brake-stand --script my_vr.luau [--mass 70000] [--ratio 2.5] [--table]
openrts-brake-stand --kind 292|483|305
openrts-brake-stand --kind 483 --load empty|medium|loaded [--mountain]
openrts-brake-stand --kind 292 --plug К|Д|УВ
```

`--load`, `--mountain` и `--plug` ставят переключатели, как меню вагона
(`--plug` понимает К / Д / УВ и K / D / UV); скрипт видит их в `c.load`,
`c.mountain` и `c.plug`.

Программа, с пустого вагона:

| Время, с | ТМ | Что меряется |
|---|---|---|
| 0–300 | зарядка до 5,0 | за сколько ЗР доходит до 4,9 |
| 300–360 | ступень 0,5 (4,5) | ТЦ и за сколько он доходит до 95 % |
| 360–450 | отпуск до 5,0 | за сколько ТЦ < 0,4 |
| 450–510 | полное служебное (3,5) | ТЦ |
| 510–570 | отпуск со сверхзарядкой до 5,6 | |
| 570–840 | сверхзарядка снимается на 0,15 атм в минуту | мягкость: любой подъём ТЦ (правильно — 0) |
| 840–900 | экстренное | за сколько до 95 % полного ТЦ |

`--table` добавляет давления каждые 10 с. ВР, который тормозит при
медленном снятии, помечается `(ТОРМОЗИТ)` — это и есть «ползучесть», которая
есть у ВР самой RTS.
